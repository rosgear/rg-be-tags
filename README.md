## <img src="https://raw.githubusercontent.com/rosgear/rg-be-tags/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Менеджер меток»

Модуль входит в состав Панели управления GePanel.

Модуль Менеджера меток обеспечивает управление метками веб-сайта, позволяя присваивать их различным типам контента (материалам, ссылкам и прочим элементам) для систематизации и упрощения поиска.

### Скриншот
<img src="https://github.com/rosgear/rg-be-tags/blob/main/assets/help/grid.png?raw=true">

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-tags
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-tags": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-tags/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

## <img src="https://raw.githubusercontent.com/rosgear/rg-be-tags/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Tags Manager»

The module is part of the GePanel Control Panel.

The Tags Manager module allows you to manage website tags, allowing you to assign them to different types of content (materials, links, and other elements) to organize and simplify searching.

### Screenshot
<img src="https://github.com/rosgear/rg-be-tags/blob/main/assets/help/grid.png?raw=true">

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-tags
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-tags": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-tags/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
